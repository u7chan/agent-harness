# UI Evidence

ユーザー可視のサーフェスを変更する PR では、現在のエージェントが変更前後の証跡を取得し、PR 本文の証跡節を更新する。レビュアーは証跡を生成しない。証跡コメントは投稿しない。節の形式、配置、添付、`head` の更新、再利用、`pr.read` による確認は [_docs/pr-evidence.md](../../_docs/pr-evidence.md) を正本とする。

## 対象

- 差分がユーザー可視の UI（画面、テンプレート、CSS、文言、操作フロー）を変更する場合。
- リポジトリの指示が証跡を要求する場合。
- 判断できない場合は、証跡なしと決めつけず、ユーザーに一度だけ確認する。
- 証跡が不要と判断した場合は、その理由を完了報告に残し、本文に証跡節を作らない。

## 取得

- [Playwright](../../playwright/SKILL.md) を使い、変更前と変更後の状態、または完了状態を最小枚数で撮る。
- Before/After の静止画には、変更箇所の印を付ける。印の付け方、撮影手順、撮影後の確認は [Playwright の証跡手順](../../playwright/references/evidence.md) に従う。After だけを撮る場合も、変更箇所に印を付ける。
- 時間経過に依存する主張だけ動画を使う。動画が 10 MB を超える場合はスクリーンショットへフォールバックし、その理由を記録する。
- 成果物は `PW_ARTIFACT_DIR` などの一時ディレクトリに置き、リポジトリへコミットしない。

## 更新

- PR 作成前に証跡が揃う場合は、`pr.create` の本文に証跡節を含め、`attachments` で画像を添付する。PR 作成後に揃う場合、または PR が既にある場合は、`pr.update` で節を挿入または差し替える。
- 節の形式、配置、添付、`head` の更新、再利用、`pr.read` による確認は [_docs/pr-evidence.md](../../_docs/pr-evidence.md) に従う。
- 修正 push が UI を変える場合は、その head の証跡で節を差し替える。変えない場合は前回の証跡を再利用し、開始マーカーの `head` だけを最新 head に更新して、その旨を節と完了報告に書く。
- PR 本文の証跡節が現在 head を指していることを、完了報告の前に `pr.read` で確認する。
